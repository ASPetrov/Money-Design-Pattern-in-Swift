# Спецификация за README и потребителската документация

## README и инсталиране

Кореновият README остава кратък вход към проекта. Посочи предназначението на MoneyFramework, минималните версии, инструкциите за добавяне през Xcode и `Package.swift` и името на продукта. Добави преки връзки към статията на двата езика, MIT лиценза и `AGENTS.md`.

Документирай добавянето директно по Git URL през Xcode и SwiftPM. До първото проверено SPM издание посочи клона с публикуван `Package.swift`. В етап 6 премини към проверен SPM таг. Историческите CocoaPods версии и стъпките за миграция са в отделен документ, свързан от README. [Спецификация за SPM миграция](SPM-Migration.md)

## Урок и примерното приложение

`Documentation/EN/` и `Documentation/BG/` съдържат по една статия с практически урок и раздел за офлайн приложението. Българската документация заменя предишния PDF.

Урокът развива един сценарий с разходи в две валути. Представи сума и валута, сравни стойностите след изрично конвертиране и раздели общата сума без загуба на минимална единица. Всеки кратък пример подготвя следващата стъпка и показва очаквания резултат. Свържи описанието на Money Pattern на Fowler и посочи статията на Patkos Csaba като вдъхновение за подхода. [Martin Fowler — Money](https://martinfowler.com/eaaCatalog/money.html) · [Money Pattern — Envato Tuts+](https://code.tutsplus.com/money-pattern-the-right-way-to-represent-value-unit-pairs--net-35509t)

Инструкциите за приложението описват локалния пакет, споделената схема, примерните курсове и командата за тестове на симулатор. [Спецификация за примерното приложение](Sample-App-Design.md)

## Критерии за приемане

- Отделен потребителски проект се компилира с документираната зависимост и импортира `MoneyFramework`.
- Swift блоковете в двата урока съвпадат и изпълненият пример дава описаните резултати. Повтори проверката срещу публикувания таг в етап 6.
- README препраща към двата езика, лиценза и указанията за хранилището. Офлайн демонстрацията е част от същия сценарий в двата урока.
