# Спецификация за deprecation на публичния API

## Обхват

Трите декларации са публични в `3.0.0`. В библиотеката, демото, тестовете и ръководствата вече се използват техните заместители или липсват извиквания на конкретните декларации.

| Декларация | Заместител | Основание |
| --- | --- | --- |
| `Money.decimalNumber` | `money.amount` | Двете свойства връщат една и съща стойност от тип `Decimal`. |
| `LocaleCurrency.current()` | `LocaleCurrency()` | Инициализаторът използва текущия locale и има същия failable договор. |
| `LocaleCurrency.currency(for:)` | `LocaleCurrency(locale: locale)` | Фабриката делегира към същия failable инициализатор. |

## Имплементация

1. В следваща minor версия на `3.x` добави `@available(*, deprecated, renamed: "amount")` към `Money.decimalNumber`. Приложи атрибута само върху свойството на `Money`, за да остане активен договорът на `DecimalRepresentable` за скаларите.
2. Добави `@available(*, deprecated, message: ...)` към двете фабрики с изрично посочен заместител. `LocaleCurrency()` и `LocaleCurrency(locale:)` запазват съществуващите условия за връщане на `nil`.
3. Документирай заместителите в бележките за minor версията. Запази публичните сигнатури и поведението през `3.x`. Премахването може да се планира при следваща major версия след публикувана minor версия с предупрежденията. [Semantic Versioning](https://semver.org/spec/v2.0.0.html)

## Приемане

- Външен SwiftPM пакет компилира старите извиквания с очакваните предупреждения и новите без предупреждения за deprecation.
- Сравнението на публичния API с `3.0.0` потвърждава, че трите декларации са налични. Изпълняват се тестовете през двата SPM манифеста.
